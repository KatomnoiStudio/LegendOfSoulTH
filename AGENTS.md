## The two layers — this file is the shared one

**`AGENTS.md` + `.agents/rules/**` is the SHARED layer.** It is written to be actionable by a
dev on any agent platform, with no particular tooling installed. Nothing in it requires a
program you may not have — where a rule cites where a finding came from, that is provenance,
not an instruction to go run something.

**`CLAUDE.md` is the LOCAL layer, and it is gitignored.** Whatever a given machine loads on
top of the shared law — its own agent tooling, the roles that machine plays, procedures that
only exist there — lives in that machine's own `CLAUDE.md` and costs nobody else a token.
Start yours by copying the tracked one-line `CLAUDE.md.example`.

**The test when writing any new rule**: can a dev with none of your tools installed act on
this sentence? Yes → it belongs here. No → it belongs in your `CLAUDE.md`.

## ⚖️ MANDATORY LAW FOR ALL AGENTS

Everything below and everything under `.agents/rules/**` is binding on every agent, every
machine, cloud sessions included. **Conform the code to the rules, never the rules to the
code** — if a rule looks wrong, say so out loud and leave it standing; a disagreement gets
recorded in the PR or commit message, never resolved by quietly editing the rule to match
what you just wrote. HetCreep owns this repo and can change any of it by saying so; that
needs no clause here, because their word is not a rule tier — it is the instruction itself.

**When two rules conflict**, the more specific one wins, in this order: `AGENTS.md` root
mandates → `.agents/rules/*.md` (this project's own laws) → `.agents/rules/ecc/PROJECT-OVERRIDES.md`
→ `.agents/rules/ecc/{react,typescript,web}/*` → `.agents/rules/ecc/common/*`. About to
violate a higher one to satisfy a lower one? Stop and flag it instead.
